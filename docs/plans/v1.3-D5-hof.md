# v1.3 D5 — Hall of Fame deletion (plan)

## 1. Scope summary

Delete the Hall of Fame system end-to-end. HoF was the data backing the F.28 eulogy modal: four "notable creature" snapshots (`first_mover`, `biggest`, `weirdest`, `last_survivor`) plus running bookkeeping (`longest_lived` fallback, `weirdest_distance`, founder anchors used for weirdness distance). Per the brief §"Deletions" #5 and the amendments Q7 row "Eulogy modal — DELETED (per D5)", the entire system is stripped:

- The `HallOfFame` struct (`src/hof.rs`) and the module itself.
- All HoF fields on `World` (and the matching fields in the SaveV1 snapshot — see cross-piece dep on D1).
- The HoF capture sites in `tick.rs` (movement step for `first_mover_snapshot`, `collect_deaths` for `last_survivor` / `longest_lived` / `weirdest`) and in `world/mod.rs::handle_births` / `World::new` (for `biggest_ever` seeding).
- The `hof_json()` wasm export and its three Rust unit tests.
- The TS eulogy module (`web/src/eulogy.ts`), the `showEulogyCard` wiring in `web/src/main.ts`, the `.eulogy-*` CSS block, and `renderCreaturePortrait` in `web/src/render.ts` (only used by the eulogy card).
- The first-mover capture branch in `apply_movement_and_repulsion`. **Note:** the `first_move_fired` / `first_eat_fired` *flags themselves* are EventLog gates owned by D4 — leave them alone here; D5 only strips the `first_mover_snapshot` write and the `HallOfFame { ... }` literal at that site. After D4 lands, the gates may go too (or not — that is D4's call), but **D5 must not touch them.**
- The `founder_genome_anchor` / `founder_brain_anchor` fields, which exist *only* to feed `species_distance` for the weirdness calculation. With weirdest gone, the anchors have no remaining consumer in tick/mod beyond their construction site. (D10 — Species deletion — will independently delete `species_distance` and the `species` module. D5 removes the anchor *fields* and their feed; D10 removes the *function*. If D5 lands first, the call disappears and `species_distance` becomes dead-code that D10 cleans up. If D10 lands first, the call site is already a compile error D5 must repair by removing the whole `weirdest` block. Either order works.)

This is a pure deletion; no new behavior, no new types, no replacement panel. Net Rust delta is roughly −180 lines; TS delta roughly −180 lines plus the CSS block.
