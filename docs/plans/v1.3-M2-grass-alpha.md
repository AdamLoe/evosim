Per modification #2 in the brief:

> **Grass color always full alpha regardless of density.** Render layer paints a fixed-alpha green for any cell with `density > 0`. Cells with `density == 0` still don't paint. Visual simplification — drop the alpha-modulation by density.

This piece touches the **render layer only**. The sim, `GrassGrid`, density values, bilinear sampling, NN grass-patch inputs, eat/graze mechanics — none of that changes. The only change is the fillStyle expression inside `drawGrassMap` at `/home/adamg/evosim/web/src/render.ts:183`.

Concretely:
- Replace `rgba(60,180,60, 0.4 * density)` with a fixed-alpha green for any cell with `density > 0`.
- The existing early-out `if (d <= 0.0) continue;` already covers the "don't paint zero" requirement and stays as-is.
- All cells with non-zero density paint with identical color — no gradient, no shading.

This is the smallest mod in the v1.3 pass. ~3 lines of effective code change.

## 3. Structs / types / constants / fields removed, added, or changed

**Removed:** none.

**Added:** one new module-local constant in `/home/adamg/evosim/web/src/render.ts`:

```ts
// v1.3 M2: uniform-green grass. Painted for any cell with density > 0.
// Density no longer modulates alpha. See docs/plans/v1.3-M2-grass-alpha.md.
export const GRASS_FILL = "rgba(60, 180, 60, 0.55)";
```

Why these values:
- **RGB stays at `(60, 180, 60)`** — matches the v1.2 green.
- **Alpha = `0.55`** — recommended value, slightly above v1.2's peak-density α=0.4.
- **Module-level `export const`** so inspector/debug overlays can reference the same constant.

**Changed:** `drawGrassMap` body. Before:

```ts
if (d <= 0.0) continue;
ctx.fillStyle = `rgba(60,180,60,${(0.4 * d).toFixed(3)})`;
ctx.fillRect(sx, sy, cellPx + 1, cellPx + 1);
```

After:

```ts
if (d <= 0.0) continue;
ctx.fillStyle = GRASS_FILL;
ctx.fillRect(sx, sy, cellPx + 1, cellPx + 1);
```

Hoist the `ctx.fillStyle = GRASS_FILL` assignment **above the loop** as a micro-optimization.
