## 2. Function-by-function change spec

### 2.1 `SpatialGrid::cell_of` (`src/grid.rs:46-50`)

```rust
pub fn cell_of(x: f32, y: f32) -> usize {
    // Toroidal world: wrap into [0, HASH_DIM) via integer rem_euclid.
    let ix = (x / HASH_CELL).floor() as i32;
    let iy = (y / HASH_CELL).floor() as i32;
    let ix = ix.rem_euclid(HASH_DIM as i32) as usize;
    let iy = iy.rem_euclid(HASH_DIM as i32) as usize;
    iy * HASH_DIM + ix
}
```

Reason: integer `rem_euclid` is bit-stable. Inputs are well-behaved finite floats because the speed cap (`MOVE_SPEED_MAX = 5.0` + `REPULSION_MAX`) keeps per-tick displacement bounded; the new `wrap_pos` ensures stored positions live in `[0, WORLD_SIZE)`.

### 2.2 `SpatialGrid::for_each_in_radius` (`src/grid.rs:83-100`)

```rust
pub fn for_each_in_radius(&self, x: f32, y: f32, radius: f32, mut f: impl FnMut(usize)) {
    debug_assert!(radius <= WORLD_SIZE * 0.5,
        "for_each_in_radius requires radius ≤ half-world (300u); got {radius}");
    let dim = HASH_DIM as i32;
    let lo_x = ((x - radius) / HASH_CELL).floor() as i32;
    let hi_x = ((x + radius) / HASH_CELL).floor() as i32;
    let lo_y = ((y - radius) / HASH_CELL).floor() as i32;
    let hi_y = ((y + radius) / HASH_CELL).floor() as i32;
    for iy in lo_y..=hi_y {
        let wy = iy.rem_euclid(dim) as usize;
        let row = wy * HASH_DIM;
        for ix in lo_x..=hi_x {
            let wx = ix.rem_euclid(dim) as usize;
            let c = row + wx;
            let s = self.starts[c] as usize;
            let e = self.starts[c + 1] as usize;
            for &idx in &self.indices[s..e] {
                f(idx as usize);
            }
        }
    }
}
```

The radius-<-half-world assertion is the master §F #4 contract. **Decision:** strict less-than assertion; vision_range_max ≤ 80u, well under 300u.

## 3. Toroidal primitives — `src/torus.rs` (new module)

```rust
//! Toroidal world arithmetic. World is WORLD_SIZE × WORLD_SIZE with
//! wrap-around on all four edges. See v1.2 grass mechanic brief and
//! DECISIONS.md (v1.2 toroidal-world deviation).

use crate::constants::WORLD_SIZE;

pub const WORLD_HALF: f32 = WORLD_SIZE * 0.5;

#[inline]
pub fn wrap_pos(p: f32) -> f32 {
    let mut q = p;
    if q < 0.0 { q += WORLD_SIZE; }
    if q >= WORLD_SIZE { q -= WORLD_SIZE; }
    // Defensive general path:
    if q < 0.0 || q >= WORLD_SIZE {
        q = p - WORLD_SIZE * (p / WORLD_SIZE).floor();
        if q >= WORLD_SIZE { q -= WORLD_SIZE; }
    }
    q
}

#[inline]
pub fn torus_delta_component(d: f32) -> f32 {
    let mut r = d;
    if r > WORLD_HALF { r -= WORLD_SIZE; }
    else if r < -WORLD_HALF { r += WORLD_SIZE; }
    r
}

#[inline]
pub fn torus_delta(dx: f32, dy: f32) -> (f32, f32) {
    (torus_delta_component(dx), torus_delta_component(dy))
}

#[inline]
pub fn torus_dist_sq(x1: f32, y1: f32, x2: f32, y2: f32) -> f32 {
    let (dx, dy) = torus_delta(x2 - x1, y2 - y1);
    dx * dx + dy * dy
}
```

Placement justification: dedicated module avoids polluting `grid.rs`, gives focused unit-test home, no circular dependency. `pub(crate) mod torus;` at `src/lib.rs:11`.

## 5. `for_each_in_radius` wrap algorithm

Algorithm in words:
1. Compute the unwrapped bounding box `[lo_x, hi_x] × [lo_y, hi_y]` in cell coordinates.
2. Under the `radius < half-world` contract, box has width and height `≤ HASH_DIM` cells.
3. Iterate `ix in lo_x..=hi_x` and `iy in lo_y..=hi_y`. For each, wrap into `[0, HASH_DIM)` via `rem_euclid`.
4. No cell visited twice because `hi - lo + 1 < HASH_DIM` strictly.

Seam case: creature at `x=595` with `radius=10` → `lo_x=117, hi_x=121`. Wrap maps `121 → 1`, `120 → 0`, so cells visited are `{117, 118, 119, 0, 1}` — 5 cells, correct count.

5. **Repulsion order across seam.** `j > i` filter for pair uniqueness still works under torus geometry. No risk.
