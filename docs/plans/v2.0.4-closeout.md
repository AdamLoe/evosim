# Close-out: v2.0.4 — grass LOD config + scatter perf + fertility + far NN sight

**Review — start here.** The v2.0.4 orchestrated effort is **code-complete and
fully gated green on both feature sets.** This is the one-page lead handoff: what
shipped, the gate evidence, what was dropped and why, and the items that need your
ratification or feel-tune. The blow-by-blow log lives in
[`v2.0.4-grass-tuning-perf.md`](v2.0.4-grass-tuning-perf.md) (the orchestration
hub); durable facts have been migrated into the owning `architecture/` and
`decisions/` docs.

## TL;DR

Five independent streams shipped and one was dropped:
- **S1 LOD config**: budget raised 2048 → **4096**, single-sourced in Rust and
  emitted to TS via `gen_bindings`; `lod_bias` slider (idx 60); aspect-ratio fix.
- **S3 scatter perf (C1+C2+C3)**: per-tile stack scratch (no heap alloc); profiling
  gated behind `profile_scatter` flag (eliminates false-sharing); fused RNG
  (`grass_hash_fused_4`, 2 hashes → 4 values).
- **S4 fertility**: spread amount ∝ source density; `GRASS_DECAY_PCT_DEFAULT` 0.02 → 0.04.
- **S6 far NN sight**: `GrassBandsFar` 8 sectors at 160u/mip-3 default ON; toggle kept.
- **S2 grass_size**: configurable cell-size slider (idx 62, 5–20u, default 5.0).
- **S5 (geometric-skip + rare-event) DROPPED** — net-harmful by measured bench.

`SLIDER_COUNT` is now **63** (was 60). The snapshot slot grass/biome regions are
`min(grass_dim, 4096)²` bytes each (up from 2048-budget; ~4× the old slot size
when grass_dim > 2048).

## S5 drop rationale

S5 (geometric-skip spread sampler + rare-event spread tuning, C4+C5) was **dropped**
after the S0 attribution bench. Key results:

- **Geometric-skip is net-harmful: +0.49 ns/cell at 6.25% fill, +18.7 ns/cell at
  ~90% fill.** The compact-list build is O(grassy); the freeze+decay O(tile) floor
  (48% of total cost at dense fill) is untouched. The "cheap spread-gate reducer"
  form always loses.
- **RNG is the dominant per-cell cost at dense fill** (3.05 ns/cell, 47% of 6.42 ns/cell
  total) — this verdict justified C3 (fused RNG), which did ship.
- The only skip path that would pay requires restructuring freeze around an event
  list — the full event-sampling refactor in
  [`perf-optimization-ideas.md`](perf-optimization-ideas.md) §3, an explicit
  non-goal for this wave.

The S0 bench findings are in [`v2.0.4-s0-attribution.md`](v2.0.4-s0-attribution.md)
(recon scratch, deletable with the effort). The S5 drop is documented in
`decisions/sim.md` under "Geometric-skip dropped."

## ⚠ Ratification / feel-tune items (these are yours)

1. **`GRASS_DECAY_PCT_DEFAULT = 0.04` (feel-tune).** Raised from 0.02 to give
   decay headroom alongside the density-weighted spread clumping. The persistence
   invariant (plains super-critical, water sub-critical) is mechanically tested;
   whether 0.04 produces the right living-noise aesthetic in the browser is a taste
   call. Tune in the browser with the live `grass_decay_pct` slider.

2. **`lod_bias` default 0.0 (feel-tune).** A default of 0 applies no LOD nudge —
   the computed mip level drives fully. If you want a built-in finer-detail offset
   at typical zoom levels, adjust the default in `DEFAULTS` in `settings.ts`.
   Note: biasing finer than the budget can hold crops viewport edges.

3. **S6 band count / radii / the walled+species single-band fallback.**
   One far band at `GRASS_FAR_SIGHT_RADIUS = 160u` / `GRASS_FAR_MIP_LEVEL = 3`
   shipped default ON. The A/B (multi-band vs single-band) is a regression guard
   confirmed not-worse. If different radii or a second far band are wanted, change
   the constants in `src/constants.rs` and re-run the gate. The walled+species
   fallback (auto-downgrade to single-band because 56 padded > `MAX_NN_INPUTS = 48`)
   is documented and not an error — confirm the fallback behavior is acceptable in
   that configuration.

4. **`grass_size` range 5–20u (feel-tune).** Range chosen as a principled perf
   lever; the exact upper bound (20u) is a taste call. Higher values mean fewer
   cells and coarser biome/grass resolution.

5. **`LUT_RADIUS = 4` pinned to 5u (safe but over-approximate at larger sizes).**
   `LUT_RADIUS` is a compile-time constant in `src/world/proximity.rs` computed as
   `ceil(GRASS_PROXIMITY_RANGE / 5.0) = 4`. This is a safe over-approximation for
   all `grass_size ∈ [5, 20]` — the LUT is larger than strictly needed at 20u
   (where `ceil(20/20) = 1`). The assert in proximity.rs is pinned to the 5u
   formula and documents this. No action required unless the proximity LUT becomes
   a significant memory or build concern.

6. **Run-to-run threaded non-reproducibility (pre-existing, unchanged).** The
   scatter kernel's lossy cross-tile relaxed RMW remains intentionally
   non-reproducible run-to-run under threads (`--features threads` / the live wasm
   sim). This carried in from the v2.0.2 grass-perf effort. The ratification item
   from the grass-perf closeout is still open; nothing in v2.0.4 changes it.
