// 2'. Grass cell count.
let expected_grass = GRASS_DIM * GRASS_DIM;
if save.grass.density.len() != expected_grass {
    return Err(LoadError::StructuralError(format!(
        "grass.density len {} != expected {}",
        save.grass.density.len(),
        expected_grass
    )));
}

// 2''. Grass densities finite + in [0, GRASS_MAX].
for (k, &d) in save.grass.density.iter().enumerate() {
    if !d.is_finite() {
        return Err(LoadError::StructuralError(format!(
            "grass.density[{k}] is non-finite: {d}"
        )));
    }
    if d < 0.0 || d > GRASS_MAX {
        return Err(LoadError::StructuralError(format!(
            "grass.density[{k}] out of range [0, {GRASS_MAX}]: {d}"
        )));
    }
}

## 11. Risks

1. **Field-order in JSON wire shape.** Serde serializes in declaration order. New ordering matters only for old-save load (which is rejected). No risk.
2. **`GrassGridSnapshot::density` is 57,600 f32s = 225 KB.** Old `SunMapSnapshot` was ~3 KB. Save size jumps to ~500-800 KB. Within IDB limits. Future v1.3 could RLE-compress.
3. **`validate_save` per-cell loop** is 57,600 iterations × 3 checks. ~0.5 ms on x86_64. Acceptable.
4. **Serde tolerance to unknown fields.** Default ignores unknown but errors on missing. v1 payload's `sun` ignored, missing `grass` errors. Confirmed safe.
5. **`from_save_v1` move of `save.grass.density`.** Reads AFTER SoA work (same position pattern as current code). Safe.
6. **Hash-collision sensitivity at v1↔v2 boundary.** PR-1 regen #1 produces new hash. Booked in master §D.1.
7. **Test `f26_sun_round_trips_exactly` deletion vs P1b.** P1b deletes the test (it references `w.sun.*`). P1f only ADDS the new grass equivalents.
8. **`Carrion.sun_cell` deletion vs sun-cell-indexed code.** P1b owns runtime deletion; P1f inherits serde-shape change.
9. **`scratch` Vec zero-init on load.** Correct IFF P1c's `step` writes scratch before reading. **Cross-check item for P1c plan reviewer.**
