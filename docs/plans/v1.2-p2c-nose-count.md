## 3. Validation domain & mutation kernel

`NOSE_VALID = [0, 1, 2, 3, 4, 5]` declared in `src/constants.rs` near L106 (after `EYE_VALID`):
```rust
pub const NOSE_VALID: [u8; 6] = [0, 1, 2, 3, 4, 5];
```

Mutation kernel (insert after `src/genome.rs:195`):
```rust
if rng.unit() < r.nose_count * rate_multiplier {
    let cur_idx = NOSE_VALID
        .iter()
        .position(|&v| v == self.nose_count)
        .unwrap_or(0);
    let mut candidates = [0u8; 2];
    let mut n_candidates = 0usize;
    if cur_idx > 0 { candidates[n_candidates] = NOSE_VALID[cur_idx - 1]; n_candidates += 1; }
    if cur_idx + 1 < NOSE_VALID.len() { candidates[n_candidates] = NOSE_VALID[cur_idx + 1]; n_candidates += 1; }
    if n_candidates > 0 {
        self.nose_count = candidates[rng.index(n_candidates)];
    }
}
```

Validation: clamping implicit — mutation only assigns from `NOSE_VALID`. Mirror eye_count exactly.

## 8. Risks

1. **No "all traits" iteration in codebase** — confirmed. Field-by-field everywhere. Adding nose_count purely additive. **No risk.**
2. **eye_count `u8 ∈ [0,5]` validation** — no post-mutation clamp; domain closed under index-adjacent-pick. Same for nose_count.
3. **Schema-version cascade interacts with P2g.** P2c does not bump; P2g does. If P2c lands without P2g and save written between, next load could deserialize without nose_count → silent data loss. **Mitigation:** land in same PR (PR-2 commit order P2g step 7).
4. **Snapshot-hash position determinism.** "Mirror eye_count exactly" interpreted structurally → position after eye_offsets[]. Cross-review confirms.
5. **TraitMutationRates serde shape change** — same JSON-shape risk. Same mitigation (schema bump).
6. **Species distance metric** — `species_distance` at `src/species.rs:156-161` walks eye_count categorically. nose_count NOT factored into species distance in this piece (out of scope). Flag for closeout; future work.
7. **Hot-mirror invariant audit** — every site that mutates `genomes[i].eye_count` in place currently calls `resync_hot_mirrors_at(i)`. Same discipline for nose_count. No in-place mutation outside `mutate_in_place` (called at child birth, before push). **No risk** but P2d/P2e implementers must respect.
