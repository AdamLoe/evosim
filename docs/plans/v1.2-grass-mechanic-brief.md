## What the user resolved (LOCKED)

### World shape
- **Toroidal world.** Wrap-around on all four edges. No walls. The `is_at_wall` NN input is removed entirely (one fewer input slot).
- All distance / raycast / repulsion / `for_each_in_radius` math wraps. `SpatialGrid::cell_of` and cell arithmetic become modular.

### Grass storage
- New `GrassGrid` struct. **2.5u cells**. World is 600u square → **240×240 = 57,600 cells**.
- Storage: flat `Vec<f32>` (and `Vec<f32>` scratch for the propagation tick), density clamped to `[0, GRASS_MAX]`.
- Independent of `SpatialGrid` resolution (which stays at 5u). The two grids coexist.

### Grass dynamics per tick
```text
grass_next[c] = clamp(
  grass[c]
    + r_in_cell * grass[c] * (1 - grass[c] / GRASS_MAX)  // logistic; only fires if grass[c] > 0
    + k_propagate * sum_of_4_cardinal_neighbors(grass, c),
  0,
  GRASS_MAX
)
```
- Empty cells with no grassy neighbors stay empty (no spontaneous spawn).
- Clumps grow faster naturally because they receive 2–4 inbound contributions per tick.
- Implementable as a single 2D convolution with the cross-kernel `[[0,k,0],[k,1+r,k],[0,k,0]]` plus the logistic correction. SIMD-friendly via the existing `wide` crate.
- Toroidal: cardinal-neighbor lookup wraps modulo 240.
- Defaults: `r_in_cell = 0.005`, `k_propagate = 0.05`, `GRASS_MAX = 1.0`. All dev-panel sliders.

### Initial grass seed
- At world init, N random cells get seeded with `GRASS_MAX` density.
- N is a dev-panel slider, default 8. Seeded via the world RNG (deterministic).

### Action set
- **8 actions still**: Rest, Move, Eat, Scavenge, Split, Armor, Pigment, **Graze** (replaces Photosynth in the same enum slot).
- Brain output dimension unchanged at 8.

### Graze mechanic
- Multi-cell: creature consumes grass from **every grass cell that overlaps its body circle**.
- Overlap test: cell's center point is within `creature.radius` of `creature.position` (toroidal distance).
- Per-cell consumption: `delta = min(grass[cell], GRAZE_MAX_PER_TICK * graze_efficiency)`.
- Total energy gained = sum of deltas across all overlapping cells, multiplied by efficiency.
- `GRAZE_MAX_PER_TICK` is a constant (or slider). Per-cell cap prevents one creature draining a max-density cell in one tick.

### Genome trait rename
- `photosynth_efficiency` → `graze_efficiency`. Same range, mutation, hash bytes. This is a pure rename in code.

### NN inputs
- Old: 136 (120 vision + 16 extras including `is_at_wall`).
- New: **160** = 120 vision (unchanged) + 15 extras (`is_at_wall` removed) + **25 grass-patch inputs** (5×5 sample around creature).
- The 25 grass-patch inputs are **bilinear-sampled** at the creature's continuous position, on a 5×5 grid stepping at 2.5u (matching `GrassGrid` cell size). Sample positions: `(cx + dx*2.5, cy + dy*2.5)` for `dx, dy ∈ {-2,-1,0,1,2}`, wrapped toroidally.
- Brain weight matrix shape: `136×24` → `160×24` (hidden layer unchanged at 24, output unchanged at 8). Save schema bump required.

### Bilinear sampling
- Per sample point `(x, y)`: compute the 4 surrounding cell centers; weight by inverse area; clamp/wrap toroidally.
- ~4 array reads + 3 multiplies + 3 adds per sample. 25 samples per creature per tick. Cost: ~25×7 = 175 ops/creature/tick. Negligible vs vision raycast.

### `nose_count` genome trait (NEW)
- Graduated `u8 ∈ [0, 5]`, mirrors `eye_count` exactly in mutation and hashing.
- Founders have `nose_count = 0`. Mutation creates and grows it.
- At `nose_count = 0`: all 25 grass-patch inputs to the NN are zeroed (creature is blind to grass).
- At `nose_count ≥ 1`: the patch is fed to the NN normally.
- Future-extension: `nose_count` could modulate patch resolution (1 = single value, 5 = full 5×5) — but for v1.2 it's a simple on/off threshold at 1.
- New `NOSE_COUNT_BYTES` in genome serde; ~1 byte per genome.

### Founder traits at world init
- `eye_count = 0` (blind to entities — no vision).
- `nose_count = 0` (blind to grass).
- Founder is essentially a Brownian-motion grazer. Survives only if it stumbles onto seeded grass cells. The world seed must place enough initial grass for at least one founder lineage to survive (test this).

### F.30 hardwiring (REWRITTEN)
- Minimal. Founder `Brain::founder()` is hardwired only as:
  - Hidden unit 0 = "on grass" detector: weight from `grass density at creature's home cell` (one of the 25 patch inputs, the center one) is large positive.
  - Output Graze += large positive weight from hidden 0.
  - Output Move += baseline weight + small random direction-persistence (re-roll vx/vy every ~20 ticks).
  - Output Split += weight from energy_frac (kept from current F.30).
- **Removed** from current F.30: NN_FOUNDER_ENERGY_SENSOR_STRENGTH for Photosynth, NN_FOUNDER_PHOTO_BIAS. Those constants get deleted.
- Critically: `nose_count = 0` means the patch inputs are zeroed, so the hardwired hidden-0 weight is effectively dormant until a descendant mutates `nose_count ≥ 1`. Until then, the founder lineage just random-walks and grazes when stumbled-upon. This is intentional — the user wants founders to be honestly dumb.

### Eat redesign
- Per-bite mechanic: predator gains `eat_bite_fraction * prey.energy`; prey loses the same amount.
- Default `eat_bite_fraction = 0.5`. Dev-panel slider.
- Existing `eat_efficiency` genome trait survives and scales this further (or applies as a multiplier on the transferred amount).
- Carrion: unchanged. A creature killed by predation drops carrion as today; Scavenge still works.

### Three-tier food chain (target outcome)
- Grazers (eyeless, nose-less or nose-1) → graze grass.
- Predators (eye_count ≥ 1, mouth bit set) → chase + bite for huge energy.
- Scavengers (eye_count ≥ 1, scav_eff > 0) → exploit carrion from natural deaths and from kills.
- Dev observability: TPS, jank, sub-spans (shipped in v1.1 observability). Add new counters: live grass-cell count, total grass density, mean nose_count, mean eye_count.

### Dev-panel UI (NEW)
- `~` hotkey toggles a dev panel overlay (or click a button in the top bar).
- Sliders for:
  - `eat_bite_fraction` (0.0 .. 1.0, default 0.5)
  - `grass_propagation_rate_k` (0.0 .. 0.2, default 0.05)
  - `grass_in_cell_growth_r` (0.0 .. 0.05, default 0.005)
  - `grass_initial_seed_count` (1 .. 100, default 8; affects only world-creation, not live)
  - Plus retained v1.1 sliders.
- The `WorldHandle::set_*` typed setters from v1.1 audit S17 are the wire-up surface.

### Render layer
- **Delete sun gradient + hotspot render entirely.**
- Add grass-density tint: per-cell green alpha (e.g. `rgba(60, 180, 60, 0.4*density)`).
- Carrion stays gray. Creatures unchanged.
- This is a Canvas2D-layer addition; the v1.1 WebGL2 design doc is still plan-only and untouched.

### Save schema
