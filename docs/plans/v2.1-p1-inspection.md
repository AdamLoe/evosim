# v2.1 P1 — full NN input/output inspection

Part of [`v2.1-overhaul.md`](v2.1-overhaul.md). **Do this first** — it is
the instrument used to tune P2/P3.

## Mission

Pause, click a creature, and see **everything its brain sees and decides**:
the full NN input vector labeled by group + direction, and the output
vector (`vx`, `vy`, the action logits, and the chosen action). Computed on
demand for the one selected creature.

## Scope

**In:** a sim-side call that, for one creature index, rebuilds its NN input
vector and runs one `Brain::forward`, returning labeled inputs + raw
outputs + decoded action; an inspector UI section that renders them.

**Out:** no change to the tick, the NN topology, or the snapshot layout.
Inspection recomputes — it does not log per-tick state.

## Approach (streams)

**Stream A — Rust inspect surface.** Extend
[`creature_inspect_json`](app/crates/evosim/src/wasm_api/mod.rs) (or add a
sibling `creature_nn_inspect_json`) to call `build_nn_input` for the index
and one `Brain::forward`, emitting:
- inputs as `[{group, label, value}]` using the `NnInputLayout` group set
  (`SelfMemory`, `GrassSectors` ×8 dirs, `BiomeDir` N/S/E/W,
  `CurrCellPenalty`, `CurrGrass`, `Bias`, `WallProximity` N/S/E/W,
  `CreatureSectors`, `GrassBandsFar` ×8) — directional groups labeled by
  compass sector so the UI need not know the layout;
- outputs `{vx, vy, logits:[graze, attack, split/mate], chosen}`.
  Owned: `app/crates/evosim/src/wasm_api/mod.rs`,
  `app/crates/evosim/src/world/nn.rs` (a labeled single-creature
  input+forward helper), `app/crates/evosim/src/brain/mod.rs` if a
  single-row forward needs exposing.

**Stream B — Inspector UI.** Render an "NN I/O" block in the inspector:
inputs grouped with small bars + numeric values; outputs with the chosen
action highlighted. Reuse the existing throttle (`inspect_id`).
Owned: `app/web/src/rail/inspector.ts`, `app/web/index.html` (new `#ins-nn-*`
rows), `app/web/src/styles.css`.

**Stream C — Tests.** A Rust unit test that the inspect JSON input count
matches the active `NnInputLayout` width and outputs decode to a valid
action; extend the e2e inspector spec to assert the NN I/O block populates
on creature click while paused.
Owned: `app/crates/evosim/src/wasm_api/tests/`, `app/web/tests/e2e/`.

## Exit gate

- `cargo test --lib` and `--features threads` green.
- `cd app/web && pnpm typecheck && pnpm build && pnpm test:e2e` green.
- Manual: pause, click a creature → inputs show grass-sector / biome /
  creature-sector / self-memory values and the 5 outputs with the chosen
  action highlighted; values change sensibly when you click different
  creatures.
