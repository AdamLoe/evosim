# v2.1 P4 — settings panel overhaul + minimal top bar

Part of [`v2.1-overhaul.md`](v2.1-overhaul.md). Can start after P1 and run
alongside P2/P3; its **slider-wiring** sub-stream lands last (after P2/P3
finalize the slider set).

## Mission

Collapse the top bar to four controls — **play/pause, restart,
auto-restart, ⚙ settings** — and rebuild the right-rail Settings panel into a
single navigable surface hosting **categorized sim settings + the profiler +
the NN editor**. The Inspector stays click-to-open (creature click).

## Scope

**In:**
- **Top bar:** remove the NN / Inspector / perf-toggle openers; keep pacing
  (play/pause), Restart (rerolls seed), auto-restart, and the ⚙ rail toggle.
- **Settings information architecture** (hub Q4, decided → **left sub-nav
  categories**): a vertical category list inside the panel (e.g. Energy,
  Grass, Lifecycle, World, Equilibrium, Display, Profiler, NN); clicking a
  category shows its rows. The **profiler** (relocated from `#perf-box`) and
  the **NN editor** are their own category entries.
- Preserve the existing **stage-then-apply** machinery, the construction-
  only vs live tiers, and the live-apply carve-out — only the *navigation*
  changes, not the apply semantics.

**Out:** no change to profiler internals (spans, no-rollup rule, poll
cadence) or the worker; no change to apply/cancel/reset semantics.

## Approach (streams)

**Stream A — DOM/CSS restructure.** New settings-panel skeleton with the
chosen IA; relocate the profiler container. Owned: `app/web/index.html`,
`app/web/src/styles.css`.

**Stream B — top bar + routing.** Trim `installTopBarButtons`; update rail
routing now that NN/Inspector aren't top-bar openers; keep the ⚙ / `~`
toggle. Owned: `app/web/src/main.ts`, `app/web/src/rail/index.ts`.

**Stream C — settings IA + categories.** Reorganize the dev-panel rows into
the chosen navigation; optional search. Owned:
`app/web/src/widgets/devpanel.ts`.

**Stream D — profiler relocation.** Install `installProfilerPanel` into the
settings panel section instead of `#perf-box`; keep `showProfiler`
source-of-truth coupling. Owned: `app/web/src/widgets/perf-panel.ts`,
`app/web/src/main.ts` (installer order).

**Stream E — NN editor fold-in.** Move the NN topology/mutation editor from
its own rail tab into a settings entry. Owned: `app/web/src/rail/nn-tab.ts`,
`app/web/src/rail/index.ts`.

**Stream F — slider wiring (LANDS LAST).** Wire the actual rows for the
final slider set after P2 removes genome/biome sliders and P3 adds
equilibrium sliders. Owned: `app/web/src/widgets/devpanel.ts`,
`app/web/tests/e2e/`.

## Exit gate

- `pnpm typecheck && pnpm build && pnpm test:e2e` green (update rail/settings
  specs for the new structure; the construction-only toast + apply/cancel/
  reset paths still pass).
- Manual: top bar shows only the four controls; the settings panel is
  navigable with sim categories + profiler + NN editor reachable; clicking a
  creature still opens the inspector; profiler still polls/draws.
