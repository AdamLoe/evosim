## Specific guidance from the review

These are the highest-leverage decisions baked into the mission, already locked but worth understanding:

1. **Curriculum has a `MIN_FACTOR=0.25` floor.** This is the most consequential review change. The original `factor=0` below `min_pop` would have anaesthetized selection during the regime that most needs gradient.
2. **Multi-founder seeding is in scope.** Default `FOUNDER_COUNT_DEFAULT = 8`, slider-tunable. Defends the brain redesign's evaluability against the 80% extinction-on-single-seed problem.
3. **NN landing is split into 5a (topology) + 5b (inputs).** Each commit is independently testable + revertable.
4. **`nearest_creature_color` NN input added.** 1 slot, lets prey perceive predator EMA intent. Without it, color-EMA is pure UX.
5. **Action-EMA scored by argmax-before-fallthrough**, not the final action — predators in cooldown shouldn't bleed Green.
6. **Display floor 0.15/channel** on color render so creatures aren't black-on-dark.
7. **`nearest_creature_dominant_color` + bilinear sector weighting** for `creature_proximity` (45° sectors flicker otherwise).
8. **Per-row "any non-empty" bitset on GrassGrid** — closes the mid-game grass-sector cost gap.
9. **Dynamic `N_CHUNKS` = clamp(pop/32, 4, min(16, worker_count))** — avoids small-pop false-sharing.
10. **Defer dirty-rect upload + worker-utilization widget to v1.5.1.** R8 + whole-frame meets bandwidth budget.
11. **Inspector contents specced** (action EMA + recent actions + wall proximity + cooldown; drop all genome-constant rows).
12. **Right-edge settings overlay z-indexes above inspector** (single close-button doubles for both).
13. **Quantitative success metric added:** mean creature age > 500 by tick 10,000 with default sliders + N=8 founders.
14. **Realistic budget: 2 working days.** "Half a day" was off by 2-3×. MVP cut-set available if time-constrained.
