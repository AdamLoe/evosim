## 2. Slider component helper

```ts
interface SliderSpec {
  label: string;
  min: number;
  max: number;
  step: number;
  default: number;
  onChange: (v: number) => void;
  formatValue?: (v: number) => string;
}

function makeSlider(spec: SliderSpec): HTMLDivElement {
  const row = document.createElement("div");
  row.className = "devpanel-row";
  const labelEl = document.createElement("label");
  labelEl.textContent = spec.label;
  const input = document.createElement("input");
  input.type = "range";
  input.min = String(spec.min);
  input.max = String(spec.max);
  input.step = String(spec.step);
  input.value = String(spec.default);
  const readout = document.createElement("span");
  readout.className = "devpanel-readout";
  const fmt = spec.formatValue ?? ((v: number) => v.toFixed(3));
  readout.textContent = fmt(spec.default);
  input.addEventListener("input", () => {
    const v = Number(input.value);
    readout.textContent = fmt(v);
    spec.onChange(v);
  });
  row.append(labelEl, input, readout);
  return row;
}
```

For `grass_initial_seed_count`, `onChange` writes to module-local state only.

## 5. `grass_initial_seed_count` semantics — read-only-at-world-creation

Per brief + master §F #12: stores a value but does NOT mutate live world. Feeds next world creation only.

### Storage
Module-local `let initialGrassSeedCount = 8` in `web/src/widgets/devpanel.ts`. Slider's onChange writes it.

### Read mechanism

`WorldHandle::new(seed)` takes only `seed` today. Add a builder variant:

```rust
#[wasm_bindgen(js_name = newWithGrassSeed)]
pub fn new_with_grass_seed(seed: &str, initial_grass_seed_count: u32) -> Self
```

Existing `new(seed)` stays, defaults to `GRASS_INITIAL_SEED_COUNT_DEFAULT = 8`. `main.ts:217` becomes `WorldHandle.newWithGrassSeed(seed, getInitialGrassSeedCount())`.

P1c's `GrassGrid::new(rng, seed_count)` already takes a seed-count argument (master §B P1c row). `World::new` becomes `World::new(seed, grass_seed_count: u32)` internally.

Persistence-restore path (`fromJson`) does NOT read slider — saved world's grass density IS saved state.

Devpanel exports:
```ts
export function getInitialGrassSeedCount(): number { return initialGrassSeedCount; }
```

## 11. Risks

1. **Defaults drift between TS and Rust.** Documented; v1.3 follow-up adds build-time assertion.
2. **`new_with_grass_seed` constructor compat.** Adding a second wasm constructor is novel. wasm-bindgen supports static methods. Low risk.
3. **`world.sliders.<field>` read path in grass tick.** P1c was originally specced with `step(r, k)` args. If P1c lands with hardcoded constants, sliders no-op. **Cross-piece dep; surface to P1c reviewer.**
4. **`~` keydown conflict.** No existing global keydown listener. Low risk.
5. **Visual collision with `#inspector-box`.** Different corners. No overlap unless viewport <400px tall. Accept.
6. **`grass_initial_seed_count` not persisted across reloads.** Intentional per brief. Not a bug.
