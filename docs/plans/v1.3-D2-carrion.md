# v1.3-D2 — Carrion mechanic deletion

Piece **D2** of the v1.3 simplification pass. Strips the carrion/corpse pool mechanic in its entirety: pool struct, spatial index, render layer, NN vision gray channel, NN self-state overlap input, the corpse-spawn on death, decay step, and all associated constants + tests.

Baseline HEAD: `418d72b`.

## 1. Scope summary

Carrion is the "dead creature pool" mechanic — when a creature dies, a `Carrion { x, y, pool, age, id }` was pushed into `World::carrion`, kept ≤ `CARRION_MAX_AGE` (100) ticks, scavenged via `Action::Scavenge`, fingerprinted in vision rays as fixed gray (0.4, 0.4, 0.4), and exposed to the NN as `carrion_overlap_norm` at self-state slot 6. The mechanic spans 8 files in `src/`, 1 in `web/src/`, the wasm bindings, plus three integration-test artefacts.

This piece deletes the mechanic without breaking the codebase. D3 deletes `Action::Scavenge` and D9 reshapes the NN. This plan keeps the eat/scavenge tick path coherent only for the local commit. D2 leaves `VISION_LEN = 120` and `FEATURES_PER_SECTOR = 5` UNCHANGED — D9 owns the shape change.

Net delete: ~430 lines across 8 Rust + 1 TS file. ~5 added.
