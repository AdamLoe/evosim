## 8. Risks

1. **Carrion energy bleed:** `decay_carrion` previously refunded unconsumed pool to local sun cell. After P1b, that energy disappears (per master §F #10). Side-effect: total system energy drops faster as carrion ages out; P3e tuning may need to compensate.

2. **`d19_smoke_test` energy-conservation bound:** uses `SUN_REFILL_RATE * SUN_DIM²`. Replace with grass-based bound. Coordinate with P1c on `World::total_grass_energy()` getter.

3. **E.20 live-sim test:** relies on `base_sun_rate * 3.0` for survival boost. If marginally passing in v1.1, removing may cause flake. Mitigation: substitute `grass_in_cell_growth_r * 3.0` if needed.

4. **`force_sequential_nn` test on threaded path:** round-trip via save/load works because P1f propagates schema changes.

5. **Wasm rebuild ordering for typecheck:** atomic deletion across Rust + render.ts:228 in one commit avoids partial-state breakage.

6. **Snapshot-hash byte ordering:** P1b deletes ~3200 bytes (sun walk) + 4 bytes/carrion (sun_cell). Hash changes; P1h regen handles.

7. **`SaveV1::schema_version = 1` window:** if P1b lands before P1f, autosaved JSON between commits fails to load. **Mitigation:** consolidate P1b's `src/save.rs`/`src/world/save_v1.rs` hunks into P1f's commit so SaveV1 shape and version bump are atomic.

8. **`force_sequential_nn` field** still requires `#[cfg_attr(not(feature = "threads"), allow(dead_code))]`. Unchanged.

9. **Doc/comment debt:** `world/mod.rs:1` doc updated; coordinate with P1c which adds grass mention.

10. **Build-feature interactions:** `sun.rs` has no feature gates; no `#[cfg]` involves sun. Low risk.
