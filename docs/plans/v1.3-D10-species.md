# v1.3 D10 — Species tracking deletion

## 1. Scope summary

Strip every species-tracking surface: species module, `SpeciesRegistry` field on `World`, `species_id`/`parent_species_id` SoA columns, `species_distance` helper, anchor (genome + brain weights) clones, species panel + chart UI, wasm `species_list_json` / `species_count` / third slot of `stats_sample`, every speciation/extinction event push site, species columns on the save snapshot. The population chart survives; only species panel + species chart go.

After this piece, evolution still happens (NN-weight drift survives), but no module labels a creature with lineage; no UI renders a species name. Creatures are just creatures; their color comes from M5 NN-weight hash.

Coordination:
- M4 owns species chart canvas removal in `index.html` + chart wiring. D10 drops the third slot in stats_sample + species_list_json poll.
- D4 deletes `EventLog`/`Event`/`EventKind`. D10 removes species lookups feeding pushes.
- D1 deletes `save.rs` + `world/save_v1.rs`. D10 cleans species refs.
- Anchor brain weights cloning is in `SpeciesRegistry::speciate()`, NOT `Brain::child_from`. Child weight propagation is untouched.
