## 1. Scope summary

Strip the F.30 founder NN hardwiring rewrite that landed in v1.2 P2f. After this piece:

- `Brain::founder(rng)` body is ~4 lines: allocate a `Vec<f32>` of `NN_WEIGHT_COUNT` length, fill via `rng.uniform(-NN_INIT_RANGE, NN_INIT_RANGE)`, return `Brain { weights, nn_mutation_rate: NN_MUT_RATE_DEFAULT }`.
- No code path touches `NN_GRASS_PATCH_CENTER_SLOT` to bias an "on-grass" hidden unit; no Move/Split baselines; no detector weights.
- All `NN_FOUNDER_*` constants are deleted from `src/constants.rs`.
- Test that asserts hardwired slot values (`founder_hardwiring_at_locked_slots`) is deleted.
- User accepts that founders "fail on startup often" — random extinction at startup is acceptable.

This piece is one of the simplest in v1.3. It coordinates closely with D9 (NN output shape: 8 → 5) and D3 (genome deletion eliminates per-creature dim variability), but does not produce the new dimensions itself; D9 owns the new `NN_INPUTS`/`NN_OUTPUTS` constants. D8 only deletes the hardwiring code-path and constants.
