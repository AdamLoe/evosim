### A.5 Move-bias semantics — ADD (not SET)

**Decision (cross-reviewer recommendation; surfaces as user-confirm flag in v1.2 closeout):** the per-creature `move_bias_*` velocity contribution is **additive** on top of the NN-output vx/vy, not a wholesale override. Pseudocode amendment to p2f §4.3:

```rust
// v1.2: NN forward already wrote vx/vy via decode_action.
// Add the external move-bias contribution to whatever the NN produced.
self.creatures.vx[i] += self.creatures.move_bias_x[i] * MOVE_SPEED_MAX;
self.creatures.vy[i] += self.creatures.move_bias_y[i] * MOVE_SPEED_MAX;
// Speed cap clamp follows existing logic (already in apply_movement_and_repulsion).
```

**Rationale:** SET would permanently disable NN-driven motion in all descendants — predator chase and scavenger pathing would be impossible. The brief literally reads "Move += baseline + small random direction-persistence". ADD preserves evolvability and matches the literal `+=`. SET is a one-line revert if the user prefers in closeout.

**Surface in closeout:** "Move-bias semantics: ADD (per cross-review §D recommendation, preserving NN-driven motion for evolved descendants). Brief reads `Move +=` literally; revertible to SET in one line if user prefers founder Brownian-walk to override evolved motion."

### A.8 §16 founder survival — P3e tuning ladder

**Decision:** PR-1 close (p1h regen) and PR-2 close (p2h regen) both run §16 acceptance with `grass_initial_seed_count = 8` first. If population goes to 0 at T=10000 OR fewer than 2 species exist, P3e tuning kicks in with this ladder:

1. Raise `grass_initial_seed_count` 8 → 50 (single-cell seeding).
2. If still fails, raise to 100.
3. If still fails, raise `grass_in_cell_growth_r` 0.005 → 0.01 (faster regrowth).
4. If still fails, raise `MOVE_BIAS_REROLL_INTERVAL` 20 → 60 (longer search legs per heading).
5. If still fails, surface as v1.2 closeout question. Recommend asking user about: (a) seed clumps (N patches of K=10 cells each instead of single cells), (b) raise FOUNDER_ENERGY 200 → 400.

The orchestrator's PR-1 regen ceremony attempts §16 first; if it fails, escalate per ladder, regen on success.
