## 2. New `Brain::founder` body

```rust
pub fn founder(rng: &mut SimRng) -> Self {
    // (1) Random init.
    let mut weights = vec![0.0_f32; NN_WEIGHT_COUNT];
    for w in &mut weights {
        *w = rng.uniform(-NN_INIT_RANGE, NN_INIT_RANGE);
    }

    // Layout reminders (locked by P2a/P2d per master §F #2 reading (a)):
    //   NN inputs (160): [0..9] self-state, [9..129] vision (120),
    //                    [129..135] last_action one-hot (6),
    //                    [135..160] grass-patch 5x5 (center idx 12 → global slot 147).
    //   NN outputs (8):  out[0]=vx, out[1]=vy, out[2..8]=action logits
    //                    {Rest=2, Graze=3, Eat=4, Scavenge=5, Split=6, Signal=7}.
    //   Weight layout (row-major):
    //     w_ih[h][i] = weights[h * NN_INPUTS + i]
    //     w_ho[o][h] = weights[NN_INPUTS * NN_HIDDEN + o * NN_HIDDEN + h]

    const GRASS_PATCH_CENTER_INPUT: usize = 147;
    const ON_GRASS_HIDDEN: usize = 0;
    const MOVE_BIAS_HIDDEN: usize = 1;
    const SPLIT_ENERGY_HIDDEN: usize = 2;
    const ENERGY_FRAC_INPUT: usize = 0;

    const GRAZE_OUT: usize = 3;
    const VX_OUT: usize = 0;
    const VY_OUT: usize = 1;
    const SPLIT_OUT: usize = 6;

    // (2) Hidden[0] = "on grass" detector.
    weights[ON_GRASS_HIDDEN * NN_INPUTS + GRASS_PATCH_CENTER_INPUT]
        += NN_FOUNDER_GRAZE_DETECTOR_WEIGHT;

    // (3) Output Graze += large positive from hidden[0].
    let w_ho_offset = NN_INPUTS * NN_HIDDEN;
    weights[w_ho_offset + GRAZE_OUT * NN_HIDDEN + ON_GRASS_HIDDEN]
        += NN_FOUNDER_GRAZE_OUTPUT_WEIGHT;

    // (4) Hidden[1] = Move baseline (symbolic; actual motion via external bias).
    weights[MOVE_BIAS_HIDDEN * NN_INPUTS + ENERGY_FRAC_INPUT]
        += NN_FOUNDER_MOVE_BASELINE;
    weights[w_ho_offset + VX_OUT * NN_HIDDEN + MOVE_BIAS_HIDDEN]
        += NN_FOUNDER_MOVE_BASELINE;
    weights[w_ho_offset + VY_OUT * NN_HIDDEN + MOVE_BIAS_HIDDEN]
        += NN_FOUNDER_MOVE_BASELINE;

    // (5) Hidden[2] = energy_frac reader; Split reads it.
    weights[SPLIT_ENERGY_HIDDEN * NN_INPUTS + ENERGY_FRAC_INPUT]
        += NN_FOUNDER_SPLIT_FROM_ENERGY;
    weights[w_ho_offset + SPLIT_OUT * NN_HIDDEN + SPLIT_ENERGY_HIDDEN]
        += NN_FOUNDER_SPLIT_FROM_ENERGY;

    Self { weights, nn_mutation_rate: NN_MUT_RATE_DEFAULT }
}
```

3 hidden units dedicated; other 21 stay random. Total 8 hardwired writes on top of 4032 random.

1. Raise `grass_initial_seed_count` default 8 → 30+. First lever.

3. Larger seed clumps (N patches of K cells).
