# v1.3 Master Plan — cross-piece dependency graph + per-piece manifest

Baseline: HEAD `418d72b`. Pass shape: 10 deletions + 5 modifications = 15 pieces. All locked answers from `docs/archive/v1.3-amendments.md` (Q1–Q8 + Q-perf) honored.

## 1. Executive summary

The v1.3 pass strips every non-evolution feature shipped through v1.2 — saving, carrion, genome (entirely), events, hall of fame, snapshot-hash + acceptance test, torus, F.30 hardwiring, action types Rest/Scavenge/Signal, species tracking — then applies five surgical modifications (grass cell size 5u, grass full alpha, perf, UI keepalive, NN-hash color). Creatures become structurally identical; only NN weights vary, so evolution is pure brain-weight evolution.

Expected line-delta: ~3,700 Rust LOC + ~600 TS LOC + ~310 acceptance-test LOC = ~4,600 lines of pure deletion. Modifications add ~150–300 LOC net. **Net delta target: −4,000 to −4,300 LOC** across Rust + TS, putting the post-pass codebase at ~9,500–10,000 LOC (down from 13,851).

Top 3 risks:
1. **NN input/output dim recomputation** — D3 + D9 + Q3 + M1 all cross-cut the NN input layout. Single source of truth in `src/constants.rs`.
2. **Walled-world revert under torus deletion** — D7 reverts to walls; D9 keeps walls visible via vision sentinel-gray (Q3). Must coordinate.
3. **UI panel breakage cascade** — D4 + D5 + D10 all touch `web/src/rail/*` and `web/src/main.ts`. M4 is the catch-net.
