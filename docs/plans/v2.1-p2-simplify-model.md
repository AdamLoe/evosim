# v2.1 P2 — simplify the model (cut genome, biomes → dead-grass zones)

Part of [`v2.1-overhaul.md`](v2.1-overhaul.md). Depends on P1 for behaviour
verification.

## Mission

Make the brain the **only** heritable thing and reduce biomes to a single
legible effect (no food). Remove the 6-trait body genome and all its
couplings; strip biome movement/energy penalties, keeping only the
grass-capacity cap so water/desert read as dead-grass zones creatures learn
to avoid via existing grass sensing.

## Scope

**In:**
- Remove the `Genome` struct + `CreatureSoA.genome` column, genome
  mutation, genome crossover (`Genome::crossed`), `canonical_for_biome`,
  and the `trait_mutation_sigma_multiplier` slider (idx 23).
- Revert the genome-modulated mechanics to constants: combat effectiveness
  (was `diet` + `body_size`), speed cap (was `max_speed`), metabolism/
  upkeep (was `metabolism`).
- Strip biome movement/energy effects (hub Q2, decided — food-only):
  remove `K_BIOME_SPEED`, `K_BIOME_COST`, `K_BIOME_UPKEEP`, the
  `water_movement_penalty` (21) / `desert_movement_penalty` (22) sliders,
  and the genome modulation in `movement_penalty_for`. **Keep** the biome
  grid + the grass-capacity cap on scatter writes
  (`compute_propagation_scatter`). Biomes then do exactly one thing: no food.
- Rework the NN biome inputs (`BiomeDir`, `CurrCellPenalty`) — they sensed a
  genome-modulated *penalty* that no longer exists. **OPEN (P2 design
  decision):** drop them entirely (grass sectors already signal "no food")
  vs replace with a cheap raw biome-type input. Lean: keep one compact
  biome-type signal so avoidance is directly learnable.
- New **creature coloring** scheme → **lineage / ancestry color** (hub Q1,
  decided): a hue inherited at split with a small per-birth mutation so
  descendants share a color and lineages are visible. Founders get distinct
  seed hues. Replaces the genome-derived hue in the snapshot color word.
- Settings: remove the genome + biome-penalty rows; bump `SCHEMA_MAJOR`
  (coordinate with P3 so it bumps once); update the drift fixture.

**Out:** no change to the grass scatter mechanic itself; species mode is
**not** removed (but see seeding note below); no new biome types.

## Approach (streams)

**Stream A — genome removal (sim core).** Delete `Genome`/column and rewire
every use site to constants. Owned:
`app/crates/evosim/src/creature.rs`,
`app/crates/evosim/src/world/mod.rs`,
`app/crates/evosim/src/world/tick.rs` (graze/attack/movement/energy),
`app/crates/evosim/src/brain/mod.rs` (`child_from*`, crossover no longer
carries genome), `app/crates/evosim/src/constants.rs`.

**Stream B — biome reduction.** Remove `K_BIOME_*` and the movement/energy
effects; simplify `movement_penalty_for` (or delete it) and the
`apply_movement_and_repulsion` + `energy_bookkeeping` biome branches; keep
the grass-capacity cap. Owned: `app/crates/evosim/src/world/biome.rs`,
`app/crates/evosim/src/world/mod.rs`, `app/crates/evosim/src/world/tick.rs`,
`app/crates/evosim/src/constants.rs`.

**Stream C — NN input layout.** Update `NnInputLayout::for_settings`, the
group set, the 4-way width tables, `MAX_NN_INPUTS`/padding, and the
walled+species fallback to reflect removed genome modulation and the
biome-input decision. Owned: `app/crates/evosim/src/world/nn.rs`,
`app/crates/evosim/src/world/proximity.rs` (if biome sampling changes),
`app/crates/evosim/src/constants.rs`. **Coordinate with P1**: the inspector
input labels must track this layout change.

**Stream D — coloring + render.** New color packing in the snapshot word +
renderer read. Owned: `app/crates/evosim/src/wasm_api/mod.rs` (snapshot
pack), `app/web/src/render/gl.ts`, and `architecture/render-pipeline.md` /
`shared-memory-and-protocol.md` for the packed word.

**Stream E — web settings.** Remove genome/biome-penalty widgets; schema
major bump + key removal; drift fixture. Owned:
`app/web/src/widgets/devpanel.ts`, `app/web/src/settings.ts`,
`app/web/tests/e2e/defaults-drift.spec.ts`.

**Stream F — tests.** Delete/adjust genome tests, NN width-table tests,
biome-effect tests, inspector trait rows. Owned:
`app/crates/evosim/src/**/tests/`, `app/web/tests/e2e/`.

## Risks / gotchas

- **NN width ripple.** Changing input groups shifts widths through padding,
  `MAX_NN_INPUTS`, and the species/walled fallback — re-derive the width
  table, don't patch one cell.
- **Species seeding.** `Genome::canonical_for_biome` biases founder genomes
  to their anchor biome; with genome gone, seeding just places anchors +
  spreads brains. Acceptable (species is unfeatured) but the
  `species.md` seeding step must be updated.
- **Inspector coupling.** The genome-trait rows + `movement_penalty` row in
  the inspector disappear; coordinate with P1's inspector work.
