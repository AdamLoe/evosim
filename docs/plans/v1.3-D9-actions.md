# v1.3 D9 — Action enum simplification + move_bias deletion

## 1. Scope summary

This piece executes brief deletion #9 (action set reduction) plus locked answer Q6 (move_bias deletion).

**What lands:**
- `Action` enum collapses from 6 variants (`Rest, Graze, Eat, Scavenge, Split, Signal`) to exactly 3: `Graze, Eat, Split`. Indices 0/1/2.
- `NN_OUTPUTS = 5` (was 8). Layout: `output[0] = vx, output[1] = vy, output[2..5] = action logits (Graze=2, Eat=3, Split=4)`.
- Movement happens every tick from NN `vx/vy` outputs regardless of action argmax.
- `decode_action` becomes argmax over 3 logits with first-index tiebreak, validity gating only on `Split` (energy ≥ `SPLIT_THRESHOLD`). NaN fallback → `Action::Graze`.
- `move_bias_x`, `move_bias_y`, `move_bias_reroll_at` SoA fields deleted (Q6). Per-tick re-roll loop and ADD before speed-cap in `apply_movement_and_repulsion` go.
- `MOVE_BIAS_REROLL_INTERVAL` constant deleted.
- `last_action` one-hot block narrows 6 → 3 floats.

**Out of scope (owned elsewhere):**
- Genome deletion (D3), vision feature drop (Q3), carrion deletion (D2), save deletion (D1), snapshot_hash deletion (D6), events deletion (D4).

## 5. NN input dim derivation

Operating under joint deletion: D3 (genome gone) + Q3 (vision 24×3) + M1 (grass cell 5u) + Q2 (last_action 3 floats).

### Self-state inputs (post-D3)
Was 9 slots. Becomes:
- `buf[0] = energy_frac`
- `buf[1] = age_frac`
- `buf[2] = prev_vx / MOVE_SPEED_MAX`
- `buf[3] = prev_vy / MOVE_SPEED_MAX`
- `buf[4] = cooldown_frac`

`size_norm` deleted (constant 1.0). `carrion_overlap_norm` deleted (D2). Reserved zeros deleted (D6 deletes snapshot_hash).

**5 floats.**

### Vision (Q3)
`24 × 3 = 72` floats. Wall sentinel reported through sector RGB on ray-exit.

### Last-action one-hot (Q2)
**3 floats.**

### Grass patch (M1)
**25 floats** assumed (5×5 sample grid retained, spacing doubles per M1).

### Final layout
```
[0..5)    self-state         5
[5..77)   vision            72
[77..80)  last_action        3
[80..105) grass-patch       25
Total: 105 floats
```

**SIMD alignment:** 105 % 8 = 1. Recommend pad to 112 with 7 reserved-zero slots after grass-patch. `NN_INPUTS = 112`.

### Weight matrix
```
NN_HIDDEN = 24, NN_OUTPUTS = 5, NN_INPUTS = 112
NN_WEIGHT_COUNT = 112 × 24 + 24 × 5 = 2808 (down from 4032, ~30% drop)
```

### Constants

## 8. Risks

1. **Compile breakage cascade** — 59 Action references must update together. Bundle with upstream pieces.
2. **NN dim mismatch across producer/consumer** — `Brain::founder`, `forward`, `child_from`, `build_nn_input`, tests. Each must use the constant, no hardcoded 160/8/4032.
3. **SIMD chunk panic on non-aligned `NN_INPUTS`** — pad to 112 (option 1 above).
4. **Determinism break — RNG reordering** — move_bias re-roll consumes 2 RNG draws per creature per tick. Deletion shifts all subsequent draws. **D6 must land first.**
5. **Test assertion blast radius** — ~30+ tests reference Action::Rest/Scavenge/Signal.
6. **Decode_action fallback semantics shift** — Action::Rest → Action::Graze on NaN. Burns energy attempting empty patches. Flag for orchestrator.
7. **Inspector regression** — `current_action` JSON changes; UI may not list new variants correctly.
8. **Output index mapping collision in Brain::founder** — D8 deletes hardwiring.
9. **Coordination with M1 grass patch dim** — lock M1 before D9 impl.
