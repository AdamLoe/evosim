# M5 — Color from NN-weight hash — Plan

## 1. Scope summary

Replace the deleted pigment trait (D3) with a **deterministic per-creature color derived from a hash of the NN weight vector**. Each creature's render color = function of its brain. Identical brains → identical color. Mutated children drift visually because their weights drifted.

Color is computed exactly twice per creature lifetime: at founder construction (`Brain::founder`) and at child birth (`Brain::child_from`), AFTER any mutation. The packed `u32` 0xRRGGBB is stashed on `Brain` (source of truth) AND mirrored as `color_rgb: Vec<u32>` on `CreatureSoA` (hot-mirror so render skips per-frame re-hash of 4000+ floats).

Per brief modification #5: hash → 24-bit RGB; cache as hot-mirror; inspector shows hash + raw color for debug.

Color is **NOT a unique identifier.** Hash collisions producing visually-identical creatures with different brains are acceptable. The point is rendering NN-divergence as visible color drift.

## 2. Hash algorithm

**Pick: `twox_hash::XxHash64`** (already in `Cargo.toml`, already used by `src/rng.rs::SimRng::from_string`).

Rationale:
- Already a project dependency. Compiles under both `default` and `threads` features.
- **Stable across runs and compiler versions** — NOT `DefaultHasher` (randomized).
- Fast: ~5 GB/s; hashing 4032 × 4 = 16KB f32 = ~3μs at child birth.
- Survives D6's deletion of `snapshot_hash.rs` since `rng.rs` keeps the dep.

**Algorithm:**
```rust
use std::hash::Hasher;
use twox_hash::XxHash64;

fn hash_weights(weights: &[f32]) -> u64 {
    let mut h = XxHash64::with_seed(0);
    let bytes: &[u8] = unsafe {
        std::slice::from_raw_parts(
            weights.as_ptr() as *const u8,
            std::mem::size_of_val(weights),
        )
    };
    h.write(bytes);
    h.finish()
}

fn color_from_hash(h: u64) -> u32 {
    (h & 0x00FF_FFFF) as u32  // pack as 0x00RRGGBB
}
```

24-bit truncation: 1000² / 2²⁴ ≈ 6% collision probability — acceptable (color not an identifier).

Alternatives rejected: fxhash (not stable across versions), ahash (randomized by default), DefaultHasher (randomized).

Sync rule: only writers are `push` (initializes from `Brain.color_rgb`) and `remove_indices` (swap_remove parallel).

## 4. Wiring — exact call sites

### 4a. `Brain::founder`
After D8's 4-line uniform-random init, append two lines:
```rust
pub fn founder(rng: &mut SimRng) -> Self {
    let mut weights = vec![0.0_f32; NN_WEIGHT_COUNT];
    for w in &mut weights { *w = rng.uniform(-NN_INIT_RANGE, NN_INIT_RANGE); }
    let weight_hash = hash_weights(&weights);
    let color_rgb = color_from_hash(weight_hash);
    Self { weights, nn_mutation_rate: NN_MUT_RATE_DEFAULT, color_rgb, weight_hash }
}
```

### 4b. `Brain::child_from`
Hash MUST run after mutation AND mutation-rate jitter (final weights):
```rust
pub fn child_from(parent: &Brain, rng: &mut SimRng, sigma: f32, multiplier: f32) -> Self {
    let mut child = parent.clone();
    // ... existing mutation loop ...
    // ... existing rate-jitter ...
    // M5: recompute on FINAL mutated weights, overwriting stale parent fields
    child.weight_hash = hash_weights(&child.weights);
    child.color_rgb = color_from_hash(child.weight_hash);
    child
}
```

Zero-mutation child (rate=0) keeps parent color because weights unchanged → deterministic.

## 11. Risks

1. **Hash collisions producing visually-identical creatures.** Document color is NOT an identifier. ~6% collision rate at 1000 creatures is acceptable.
2. **Cache invalidation if weights mutated outside `child_from`.** Audit (§4d) confirmed only test fixtures. Add doc comment on `Brain.weights` warning future code.
3. **NaN in weight bytes.** XxHash64 hashes raw bytes regardless. Mutation can't produce NaN. Acceptable.
4. **Endianness.** wasm32 LE; native LE. Cross-platform consistent.
5. **Brain serialization.** New fields auto-serialize. D1 deletes save; matters only for tests.
6. **Visual "all founders look similar."** Different RNG draws produce well-separated hashes via 2000+ weights.
7. **Inspector hex formatting.** `format!("#{:06X}", c)` produces 6 digits with `#`.
8. **Render flicker.** None — color computed once at birth, never changes.
