# v1.3 M1 — Grass cell size 2.5u → 5u

## 1. Scope summary

Modification #1 from the brief. Single-constant change with a derived-constant cascade:
- `GRASS_CELL_SIZE: 2.5 → 5.0`
- `GRASS_GRID_DIM: 240 → 120` (auto-derived)
- `GRASS_CELL_COUNT: 57_600 → 14_400` (auto-derived)

The grid storage shape, propagation kernel, bilinear sampler, and `for_each_cell_overlapping_circle` all parameterize on these constants and "just work" arithmetically. Compile-time `const _` invariants in `src/grass.rs` need updating. Tests hardcoding 240/57_600/2.5 must update.

Brief intent: 4× perf win on `GrassGrid::step` (14.4K cells vs 57.6K) and on every `bilinear_sample`. The 5×5 NN grass-patch sampler uses `GRASS_CELL_SIZE` as spacing — doubling the constant doubles the sample stride. Per brief: "NN grass-patch sample spacing doubles (5u between samples instead of 2.5u — patch covers a wider area)."

This is a **modification**, not a deletion. The grass mechanic itself stays.

1. **Energy balance regression — graze yield drops 4×** at best case. Founder radius 1.0 typically overlapped 1-4 cells; now overlaps 1. Mitigation: do nothing in M1; flag for Phase 6 follow-up if Phase 6 shows mass extinction.
2. **Grass spreads slower in world-space units.** Cosmetic.
3. **Bilinear sample correctness.** Math identical; coarser semantically.
4. **NN grass-patch coverage doubles to 20u × 20u.** Half vision range — intended.
5. **`graze_n_cell_overlap_sums_capped_deltas`** produces smaller overlap count. Formula-based invariant still holds.
6. **`for_each_cell_overlapping_circle` r_cells slack** — `+1` is still correct.
7. **No perf regressions identified** — `GrassGrid::step` 4× faster, `grass_buffer()` copy 4× less bandwidth.
8. **Hard-coded literals** — grep confirms zero remaining `240`/`57600`/`2.5` outside the constants module + test files audited.
