## 2. The 25-sample loop — LOCKED iteration order

**LOCKED iteration order:** `dy` outer, `dx` inner. Slot offset within the 25-block:
```text
slot_off(dx, dy) = (dy + 2) * 5 + (dx + 2)
```
Rationale: row-major matches Rust's natural array layout, matches grass density texture row-major Vec<f32> storage in GrassGrid (P1c).

**LOCKED center-slot index:** `dx=0, dy=0` → `slot_off = (0+2)*5 + (0+2) = 12` → global slot **`135 + 12 = 147`**.

This is the slot P2f's F.30 hardwiring must reference.

Pseudocode (extension of `build_nn_input`, after existing `last_action` one-hot block at L282):

```rust
// 135..160: 25 grass-patch inputs (5x5 bilinear, dy outer, dx inner; v1.2 P2d).
// Slot offset within block: (dy+2)*5 + (dx+2). Center (dx=dy=0) -> global slot 147.
let cx = creatures.x[i];
let cy = creatures.y[i];
let base = 135usize;
for dy in -2i32..=2 {
    for dx in -2i32..=2 {
        let sx = cx + (dx as f32) * GRASS_CELL;
        let sy = cy + (dy as f32) * GRASS_CELL;
        let off = ((dy + 2) as usize) * 5 + ((dx + 2) as usize);
        buf[base + off] = grass.bilinear_sample(sx, sy);
    }
}
// P2e: if creatures.g_nose_count[i] == 0 then buf[135..160].fill(0.0); (NOT in this piece)
```

`GRASS_CELL` = 2.5 (P1c).

## 4. Threaded ↔ sequential bit-identity (D.2 invariant)

**Invariant:** for any creature `i`, world state `W`, and call site (sequential vs threaded), `build_nn_input(i, …, &W.grass)` produces byte-identical `[f32; 160]`.

How preserved:
- The 25-sample loop lives inside `build_nn_input` only. Both call sites (L128-139, L171-182) reach `build_nn_input` via the same path.
- `grass: &GrassGrid` is read-only borrow during NN forward. Same pattern as `&self.creatures`, `&self.vision[..]`, etc.
- `GrassGrid::bilinear_sample(x, y)` is pure function of `(x, y, &density)`. No interior mutability, no thread-local state, no RNG. Both branches read same `density` buffer (no grass writes during NN forward — propagation is separate per-tick step).
- Iteration order fixed (`for dy in -2..=2 { for dx in -2..=2 { ... } }`); compiler cannot reorder disjoint `buf[k]` writes.

Re-affirm against master §D.2: threaded path's risk surface is reading `prev_vx/prev_vy` from `mem::take`'d slice. P2d does NOT touch that — only adds new arg + 25 writes to `buf[135..160]`. S23 test catches regression.

## 5. Determinism in `bilinear_sample`

P1c owns the helper. P2d's contract on it:
- Pure function. No globals, no libm calls (just mul/add + integer mod).
- Toroidal wrap done via `rem_euclid` on integer cell indices, NOT via float `x.rem_euclid(WORLD_SIZE)` (master §D.3):
  ```rust
  let fx = x / GRASS_CELL;
  let i0 = (fx.floor() as i32).rem_euclid(GRASS_DIM as i32) as usize;
  let i1 = ((fx.floor() as i32) + 1).rem_euclid(GRASS_DIM as i32) as usize;
  let tx = fx - fx.floor();
  // weighted sum of 4 corners
  ```
- Standard IEEE 754 round-to-nearest. No `#[target_feature]` SIMD intrinsic.
- `fx.floor()` bit-stable across wasm32 + x86_64 for finite f32.
- **Coordination requirement on P1c:** explicitly declare `bilinear_sample` `#[inline]` (not `#[inline(always)]`) with no `unsafe` interior-mut or non-deterministic ops.

Open determinism risk: position `NaN` (shouldn't happen post-S5) → all 25 slots NaN → forward NaN logits → S5's NaN guard → Rest. Acceptable failure mode.

## 7. Performance back-of-envelope

Per creature, per tick:
- 25 calls to `bilinear_sample`.
- Each: ~25 scalar ops.
- Total: ~625 scalar ops per creature per tick.

Compare to vision raycast: ~2,400 cell-visit ops per creature. Grass-patch sampling ~25% of one vision pass. Negligible.

`buf[135..160]` is 100 bytes, fits in two cache lines.

## 10. Risks

1. **P2b's exact reshuffle of slots 0..135 not yet finalized.** P2d only guarantees `buf[135..160]` ownership; tests assert only that range.
2. **`build_nn_input` signature churn.** Adding `grass: &GrassGrid` forces every call site. P2a strips F.30 hardwiring first; P2d adds arg. Test sites at L422, L456, L473 need updates. **Mitigation:** P1c expose `GrassGrid::empty()` for tests.
3. **`bilinear_sample` not yet implemented.** Hard dependency on P1c. If P1c's sample uses float modulo, seam-wrap test fails. **Mitigation:** cross-review at plan time.
4. **`force_sequential_nn` toggle (S39 (a) knob).** Threaded build S23 test forces sequential pass via `w.force_sequential_nn = true` (L816, 843). Adding `&self.grass` must mirror exactly. **Mitigation:** test #4 directly asserts.
5. **`creatures.x[i]` snapshot timing.** Threaded NN reads from `creatures_ref` borrow at L89. No mutation during parallel block (x/y only touched in `apply_movement_and_repulsion` which runs before NN). **Mitigation:** document in code; S23 already exercises.
6. **NaN propagation on NaN coords.** Position NaN shouldn't be possible (S5 guards). If it slips through, all 25 slots NaN → S5 guard → Rest. **Mitigation:** add `debug_assert!(cx.is_finite() && cy.is_finite())`.
