## 2. New Eat formula (locked)

Per brief + master §F #9 reading (b) (armor at bite site):

```text
transfer       = sliders.eat_bite_fraction * prey.energy * (1 - prey.armor)
predator.gain  = transfer * predator.eat_efficiency
prey.damage    = transfer
```

**Plain English:**
- Bite removes fixed *fraction* of prey's current energy. Fraction = `eat_bite_fraction` (dev-panel slider, default 0.5).
- Prey armor attenuates bite **at bite site**: armored prey lose less per bite.
- Predator's `eat_efficiency` is *digestion* multiplier on the predator's ledger only.
- Prey loses exactly `transfer` regardless of predator's efficiency.

### Worked example
Prey energy=100, armor=0.3; eat_bite_fraction=0.5; predator eat_efficiency=0.8:
- transfer = 0.5 × 100 × 0.7 = 35
- predator.gain = 35 × 0.8 = 28
- prey.damage = 35

Prey: 100 - 35 = 65. Predator: net +27.7 (after COST_EAT_ATTEMPT=0.3).

### Pseudocode (replacing tick.rs:286-294)

```rust
if let Some((j, _)) = best {
    let armor = self.creatures.genomes[j].armor.clamp(0.0, 1.0);
    let bite_frac = self.sliders.eat_bite_fraction;
    let prey_energy = self.creatures.energy[j];
    let transfer = bite_frac * prey_energy * (1.0 - armor);
    self.scratch_damage[j] += transfer;
    self.scratch_gain[i]   += transfer * eat_eff_i;
    self.scratch_cooldown_set[i] = true;
    self.scratch_got_a_bite[i]   = true;
}
```

`size_i` no longer needed inside the bite arm; still used at L254 for max_range.

## 10. Risks

1. **Schema-version bump cascade.** P3a adds DevSliders field → SCHEMA_VERSION 3 → 4. Master plan §B P3a row doesn't list explicit bump. **Mitigation:** include in P3a commit + DECISIONS one-liner.

2. **Energy-economy shock at PR-3 regen.** ~30× bite payout in average case. P3a + P3e together must land before PR-3 golden regen. Master §E sequence: P3e (#6) precedes regen (#7). Correctly sequenced.

3. **`scratch_damage[j]` contention under shared-prey.** Two predators biting same prey both read pre-tick `prey.energy[j]`. Combined damage can exceed `bite_frac × energy`. Matches existing behavior (damage accumulates). Not a regression but documenting in DECISIONS.

4. **Threaded NN determinism.** `eat_and_scavenge` is sequential; no threading risk.

5. **Floats near zero / negative.** `prey.energy` read at bite site = start-of-tick value (scratch_damage is the accumulator). Safe.

6. **Carrion-pool independence.** Narrative "post-death = 0" descriptive only. No code change. DECISIONS clarification.

7. **Predator self-bite or null-target.** `best` excludes `j == i`. No risk.
