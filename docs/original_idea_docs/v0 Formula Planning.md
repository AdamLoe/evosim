
What is a good game idea
- Fish eating fish
	- AI should stay away from bigger fish.
	- AI will chase after smaller fish
	- AI will learn to avoid getting pinched by larger fish
	- That's about it
- Car race
	- AI will learn staying alive
	- AI will learn taking turns fast
	- AI will learn planning for future turns
- Car survival (race 2)
	- Need to avoid obstacles
		- Will need to learn more complicated map (will need much more inputs and/or neurons)
	- Avoiding moving obstacles
		- Again, more inputs for speed, or neurons with memory for storing this
	- Will learn to pick up fuel/repairs when optimal/needed
- Mario
	- Jump / Forward at random.
	- Both all the time
	- Jump/Forward/Both when needed

2D Universe
- We want to build a brain that works somewhat like humans, so we give them less possibilities
	- Can see colors based on type of entity
		- Can eventually learn what these colors mean
	- Each entity has specific sounds for different types of things
	- Survival mechanics
		- There are bigger creatures that must be teamed up to kill
	- Crafting mechanics
		- Can only carry one thing at a time
		- When attepmting to pick up second qualifying item, it will give you an item, effect, or world item
		- These would become very useful in later brain stages
	- We ideally want to start with a fairly minimal body/brain. We can further evolve into different configs with tradeoffs
