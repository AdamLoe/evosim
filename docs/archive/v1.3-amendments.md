## Phase 0 — Pre-planning questions (2026-05-26)

### Q1–Q6 + Q-perf (pre-answered in prior session)

See `docs/plans/v1.3-simplification-brief.md` §"Open questions for the
user" for the full text. All marked **ANSWERED**. Summary:

- **Q1 (genome scope):** DELETE entirely. No traits, no pigment, no
  eye_count / size / move_speed variation. All creatures structurally
  identical; evolution = pure NN weight evolution.
- **Q2 (action enum):** `{Graze, Eat, Split}` = 3 variants.
  `NN_OUTPUTS = 5` (3 action logits + 2 movement scalars vx, vy).
  Movement happens every tick regardless of argmax action.
- **Q3 (vision):** Fixed 24-sector vision at `VISION_RANGE_MAX = 80`.
  Per-sector features = 3 (RGB only — no distance, no type). Total
  vision input = 24 × 3 = 72 floats. Walls reported as a sentinel
  gray color when rays exit world bounds. Replaces the old
  `is_at_wall` slot.
- **Q4 (persistence):** FULL deletion. No IDB, no autosave, no
  resume UX, no export. Reload = fresh world every time.
- **Q5 (test infra):** Delete acceptance test + both goldens +
  `snapshot_hash` + S39 threaded-equivalence test.
  `cargo test --lib` (default + threads) is the only test gate.
- **Q6 (move semantics):** Delete `move_bias_*` SoA fields + re-roll
  + ADD semantics entirely. Founders get pure uniform NN init.
  vx/vy come ONLY from NN output. Random extinction at startup is
  acceptable.
- **Q-perf:** Performance work open-ended. UI/render perf
  investigated FIRST (observed bottleneck). Backend perf (brain
  transpose, GrassGrid SIMD) deferred until rest of simplification
  has landed. Phase 6 follow-up if time tight.
