# v1.3 D7 — Torus revert to walled world

## 1. Scope summary

Delete the entire toroidal-world physics (v1.2 PR-1) and revert to the pre-v1.2 walled-square world. Keep the boundary perceptible via the vision raycast (per Q3 — rays exiting world bounds report sentinel "wall" RGB).

Concretely:
1. Delete `src/torus.rs` (entire file).
2. Restore wall-clamp logic in `World::apply_movement_and_repulsion` — replace `wrap_pos` with `clamp(radius, WORLD_SIZE - radius)`.
3. Restore Euclidean math everywhere `torus_delta` / `torus_dist_sq` / `wrap_pos` is called.
4. Update vision raycast to stop at world bounding box and write sentinel "wall" RGB into per-sector RGB triple when ray exits bounds (replaces deleted `is_at_wall` slot per Q3).
5. **DO NOT restore** the old `is_at_wall` self-state NN input. Wall visibility via vision rays only. Coordinate with D9 (NN input shape) and D2 (vision palette).
6. Delete all toroidal-specific tests; add replacement tests for clamp + wall-sentinel-on-ray-exit.

This piece is invasive — every spatial-distance call site currently assumes toroidal math.

## 6. Risks

1. **Repulsion math may need re-tuning** — toroidal seam was a gentle spreader. Walls cluster creatures.
2. **Spatial-index — Euclidean now** — slight perf win at edges.
3. **Vision determinism shift** — random NN init in v1.3 will adapt.
4. **Edge-clamp creates "walls of bodies" pile-up** — pre-existing pre-v1.2 behavior.
5. **GrassGrid edge dynamics change** — corner cells have lower steady-state density.
6. **`WALL_THRESHOLD_PAD` potentially dead code** — see §9.
7. **Raycast DDA termination boundary** — wall distance computation needs care.
8. **`cell_of` semantics change** — clamp, not wrap. Audit callers.
