# v1.3 D1 — Saving / persistence deletion plan

## 1. Scope summary

Delete every persistence surface from evosim. No IndexedDB, no autosave loop, no resume modal, no schema versioning, no `validate_save`, no schema-mismatch UX, no save-related tests, no `snapshot_json` / `fromJson` wasm-bindgen API. Reload is always a fresh world (subject to the `?seed=` URL parameter). Per Q4 amendment this is a FULL deletion: no fallback, no migration hooks, no commented-out scaffolding. After this piece lands the codebase contains zero references to `SaveV1`, `LoadError`, `SCHEMA_VERSION`, `to_save_v1`, `from_save_v1`, `validate_save`, `validate_soa_lengths`, `rehydrate_event_log`, `snapshot_json`, `fromJson`, or the `PersistenceClient`.
